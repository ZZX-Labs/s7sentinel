# Support

S7Sentinel is community-maintained software and is provided without warranty.

For usage questions, open a GitHub Discussion if enabled, or a normal issue when the question is not security-sensitive. For bugs, use the bug report form. For suspected vulnerabilities in S7Sentinel, follow `SECURITY.md` and do not disclose sensitive details publicly.

The project cannot provide emergency incident response, vendor patch certification, process-safety approval, or authorization to test third-party systems. For an active industrial incident, engage your organization's incident-response team, control-system engineers, appropriate vendors, and relevant government/sector reporting channels.
