# AA26-231A Defensive Control Mapping

S7Sentinel's first profile is based on the advisory text supplied with the project requirements: *Defending Against an Active Threat to Siemens S7 Series PLCs*, alert code AA26-231A, released August 19, 2026 by NSA, CISA, FBI, DOE, and EPA.

The project translates the advisory into checks for inventory completeness, firmware/patch evidence, Internet exposure, TCP/102 reachability, segmentation, remote access/MFA, engineering-workstation restrictions, PLC protection controls, logging, unnecessary services/protocols, logic-integrity verification, and local advisory correlation.
