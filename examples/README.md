# Examples

All examples in this directory are synthetic and intentionally non-production.

- `inventory.csv` contains one well-controlled and one intentionally weak PLC inventory row.
- `s7-events.csv` demonstrates unauthorized TCP/102 sources, sequential destination access, and an unticketed write-like event.
- `agentic-events.csv` demonstrates synthetic identity/API indicators including a spray-shaped failure sequence and unsafe application telemetry.

Use these files to validate installation and learn report semantics. Do not replace them in Git with real incident data.
